Please note before installing

MYCardPro+ is distributed as an APK outside the Google Play Store.

Before installing, you may need to enable Install unknown apps (Android sideloading) for the app you use to open the APK, such as your browser or file manager. Android may show a security prompt. Only allow installation for a source you trust, and turn the permission off again afterward if you prefer.

The exact setting name and location vary by Android version and device. This permission allows APK installation; it does not mean you should ignore other security warnings.
